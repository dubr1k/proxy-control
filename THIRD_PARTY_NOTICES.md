# Third-party notices

Proxy Control repository code is distributed under the repository [MIT license](LICENSE). External software keeps its own license; this file is a boundary summary, not a replacement for upstream license texts.

- **Telemt:** external MTProto runtime/container with its own public license and release artifacts. The repository pins the selected image and does not relicense it.
- **Mieru/mita:** GPLv3+ external runtime. The `mita` binary is downloaded or mounted separately and is not bundled into this MIT repository or its images. The adapter communicates across a process/Unix-socket boundary and does not include copied upstream source or generated GPL stubs.
- **Caddy and external modules/images:** separately licensed upstream components. The selected Caddy builder image and immutable `klzgrad/forwardproxy` commit are pinned in `docker/Dockerfile.caddy-naive`; `scripts/check-naive-caddy-build.sh` checks the version and required module. Review those exact build inputs, image manifests and upstream notices before redistribution.
- **amneziawg-go (AmneziaWG):** SPDX `MIT`, Copyright (C) 2017-2025 WireGuard LLC, from the Amnezia VPN project (`github.com/amnezia-vpn/amneziawg-go`, a fork of `wireguard-go`). The optional `awg-manager` container image builds it from the immutable commit pinned in `awg_manager/Dockerfile` (`b5928efb6ca19f0153958460c3d141f04abc5c2e`, tag `v3.1.20260828`); the binary is not committed to this repository. The image also installs Debian `iproute2` and `nftables` (GPL tools, separate programs invoked as processes) over the pinned `debian:bookworm-slim` base. The manager itself is a Rust binary; its crates (among them `x25519-dalek` for the keys and `rustls` with `ring` for the WARP registration) keep their upstream licenses and are pinned in `awg_manager/Cargo.lock`.
- **TrustTunnel endpoint (`trusttunnel_endpoint`):** SPDX `Apache-2.0`, the TrustTunnel project (`github.com/TrustTunnel/TrustTunnel`, AdGuard). The optional `trusttunnel-manager` container image downloads the immutable release archive `trusttunnel-v1.1.0-linux-x86_64.tar.gz` (SHA-256 `91c2ea3db7416a01b5258a4c047ec22890490bc55e1b194206031aa75144f0e7`, pinned in `release/external-artifacts.json`) while it is built and runs the unmodified binary as a subprocess; the binary is not committed to this repository.
- **Rust dependencies:** the panel, protocol managers, MCP server, installer and version-agent use crates under their respective upstream licenses. These include Tokio, Hyper, Axum, rusqlite, rustls, Argon2, AES-GCM and qrcode; resolved versions are recorded in each component's `Cargo.lock`. The MIT license of this repository does not replace those upstream licenses. Review dependency license texts and the release SBOM before redistribution.
- **Python development dependencies:** HTTPX and its transport dependencies, `pydantic_core` compatibility vectors, pytest, Ruff and their dependencies are external development, release and acceptance tools, not the panel or manager runtime. Direct pins are in `panel/requirements-dev.txt`; they retain their upstream licenses. Archived Python interoperability fixtures are test material, not a supported application runtime.

Dependency pins and URLs in tracked configuration are not an assertion that all transitive license obligations are reproduced here. Release engineering must inspect the actual resolved artifacts and include notices required by those versions.
