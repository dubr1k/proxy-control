# v2.0.1 — счётчики соединений в мониторе

[English](#english) · **Русский**

Дата: 2026-10-18. Предыдущий выпуск: [v2.0.0](https://github.com/dubr1k/proxy-control/releases/tag/v2.0.0).

## Русский

### Что нового

Это исправляющий выпуск: в мониторе появились счётчики соединений.

- **Соединения вместо нулей.** На карточках протоколов вкладки «Сейчас» у TrustTunnel, NaiveProxy и Mieru строки «Сессий» и «Клиентов» показывали 0 или «—», хотя трафик шёл: менеджеры этих протоколов не дают живого счёта. Теперь карточка показывает «Соединений N» — число установленных TCP-соединений на портах протокола. Это реальные потоки, а не клиенты: один клиент может держать несколько. Где цифры нет, карточка показывает прежнее «Сессий»; у AmneziaWG остаются «Сессий» — число пиров. Подробно — [MONITORING.ru.md](https://github.com/dubr1k/proxy-control/blob/v2.0.1/MONITORING.ru.md).
- **История и сводка.** Число соединений хранится в истории и входит в сводку как пик (`connections_peak`).
- У Mieru считаются только TCP-порты; UDP не считается.

### Что важно знать

- Это патч-выпуск: ломающих изменений нет, настраивать ничего не нужно. **Установщик в этом выпуске не менялся.**
- Обновляется панель и update-агент; после обычного `--update` агент перезапускается и начинает считать соединения сам.

### Новая установка

Используйте Ubuntu 24.04 LTS x86-64 и обычного пользователя с `sudo`, не вход под root. Подготовьте DNS-имена и следуйте [руководству по установке](https://github.com/dubr1k/proxy-control/blob/v2.0.1/README.md#установка-человеком) и [справочнику установщика](https://github.com/dubr1k/proxy-control/blob/v2.0.1/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.0.1/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.0.1/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки контрольной суммы.

### Обновление

Сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v2.0.1/docs/BACKUP_RESTORE.ru.md), скачайте и проверьте те же файлы, затем выполните:

```bash
bash install-release.sh --update
```

Порядок обновления флота прежний: сначала узлы, центральная панель последней. Тома Docker, базу и секреты при обновлении не удаляйте. Подробнее: [обновление](https://github.com/dubr1k/proxy-control/blob/v2.0.1/docs/UPGRADING.ru.md).

## English

### What's new

This is a patch release: the monitor gains connection counters.

- **Connections instead of zeros.** On the protocol cards of «Сейчас» (Now), the «Сессий» (Sessions) and «Клиентов» (Clients) lines read 0 or «—» for TrustTunnel, NaiveProxy and Mieru while traffic was flowing, because those managers give no live count. The card now shows «Соединений N» (Connections): the number of established TCP connections on the protocol's ports. These are real streams, not clients: one client may hold several. Where there is no figure the card shows the previous «Сессий»; AmneziaWG keeps «Сессий», the number of peers. Details: [MONITORING.en.md](https://github.com/dubr1k/proxy-control/blob/v2.0.1/MONITORING.en.md).
- **History and summary.** The connection count is kept in history and the summary reports its peak (`connections_peak`).
- For Mieru only the TCP ports are counted; UDP is not.

### Good to know

- This is a patch release: there are no breaking changes and nothing to configure. **The installer did not change in this release.**
- The panel and the update agent change; after the usual `--update` the agent restarts and starts counting connections by itself.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v2.0.1/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v2.0.1/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.0.1/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.0.1/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v2.0.1/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The fleet update order is unchanged: nodes first, central panel last. Do not delete Docker volumes, the database or secrets as part of an update. More: [upgrading](https://github.com/dubr1k/proxy-control/blob/v2.0.1/docs/UPGRADING.md).
