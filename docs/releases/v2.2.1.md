# v2.2.1 — все протоколы в «Состоянии сервисов»

[English](#english) · **Русский**

Дата: 2026-10-19. Предыдущий выпуск: [v2.2.0](https://github.com/dubr1k/proxy-control/releases/tag/v2.2.0).

## Русский

### Что нового

Это исправляющий выпуск: список «Состояние сервисов» на обзоре показывал только MTProxy и NaiveProxy.

- **Все включённые протоколы в списке.** Добавлены Mieru, AmneziaWG и TrustTunnel: зелёная строка, если менеджер работает, красная, если недоступен. Строки у выключенного протокола нет.

### Что важно знать

- Ломающих изменений нет, настраивать ничего не нужно. **Установщик в этом выпуске не менялся.**
- Обновляется только панель.

### Новая установка

Используйте Ubuntu 24.04 LTS x86-64 и обычного пользователя с `sudo`, не вход под root. Подготовьте DNS-имена и следуйте [руководству по установке](https://github.com/dubr1k/proxy-control/blob/v2.2.1/README.md#установка-человеком) и [справочнику установщика](https://github.com/dubr1k/proxy-control/blob/v2.2.1/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.1/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.1/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки контрольной суммы.

### Обновление

Сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v2.2.1/docs/BACKUP_RESTORE.ru.md), скачайте и проверьте те же файлы, затем выполните:

```bash
bash install-release.sh --update
```

Порядок обновления флота прежний: сначала узлы, центральная панель последней. Тома Docker, базу и секреты при обновлении не удаляйте. Подробнее: [обновление](https://github.com/dubr1k/proxy-control/blob/v2.2.1/docs/UPGRADING.ru.md).

## English

### What's new

This is a fix release: the «Состояние сервисов» list on the overview showed only MTProxy and NaiveProxy.

- **Every protocol that is switched on is in the list.** Mieru, AmneziaWG and TrustTunnel are added: a green line when the manager works, a red one when it is unavailable. A protocol that is off has no line.

### Good to know

- There are no breaking changes and nothing to configure. **The installer did not change in this release.**
- Only the panel changes.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v2.2.1/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v2.2.1/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.1/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.1/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v2.2.1/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The fleet update order is unchanged: nodes first, central panel last. Do not delete Docker volumes, the database or secrets as part of an update. More: [upgrading](https://github.com/dubr1k/proxy-control/blob/v2.2.1/docs/UPGRADING.md).
