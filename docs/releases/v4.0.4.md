# v4.0.4 — исправление обновления Naive/Caddy

[English](#english) · **Русский**

## Русский

### Что изменилось

- Исправлен отказ обновления Naive/Caddy после установки 4.0.3: каталог обновлений теперь использует закреплённый commit forwardproxy, для которого подготовлен клиентский live-счётчик, а не подвижную upstream-ветку.
- Версии Caddy и контрольные суммы сборщиков по-прежнему определяются по опубликованным upstream-артефактам. Защитный отказ неподдерживаемым commit и проверки live-счётчика сохранены.

### Обновление

Следуйте [руководству обновления](https://github.com/dubr1k/proxy-control/blob/v4.0.4/docs/UPGRADING.md): проверьте контрольную сумму `install-release.sh`, затем выполните `bash install-release.sh --update`. Сначала обновите связанные узлы, затем центральную панель отдельно. Сохраните резервную копию.

После обновления панели заново проверьте доступные версии компонентов и отдельно запустите обновление Naive/Caddy. Одно обновление панели не заменяет работающий Caddy. Для клиентского live-графика необходима сборка с модулем `proxy_control.naive_live_meter`; пока она не установлена, источник остаётся недоступным.

Настройки установщика и поведение скрипта скачивания не изменились; опубликованный скрипт закрепляет версию и SHA-256 архива 4.0.4. Новая установка использует тот же поддерживаемый commit forwardproxy. Контракты Fleet v2 и форматы подписок не изменились.

## English

### Changes

- Fix Naive/Caddy updates failing after installing 4.0.3: update discovery now uses the pinned forwardproxy revision supported by the client live-meter patch, not the moving upstream branch.
- Caddy releases and builder digests still come from published upstream artifacts. Unsupported-revision refusal and live-meter capability checks remain in place.

### Upgrade

Follow the [upgrade guide](https://github.com/dubr1k/proxy-control/blob/v4.0.4/docs/UPGRADING.md): verify the `install-release.sh` checksum, then run `bash install-release.sh --update`. Update linked nodes first and the central panel separately afterwards. Keep a restorable backup.

After updating the panel, refresh available component versions and request the Naive/Caddy update separately. A panel-only update does not replace the running Caddy. Client live charts require a build with `proxy_control.naive_live_meter`; until it is installed, the source remains unavailable.

Installer defaults and download-script behaviour are unchanged; the published script pins the 4.0.4 archive version and SHA-256. Fresh installations use the same supported forwardproxy revision. Fleet v2 contracts and subscription formats are unchanged.
