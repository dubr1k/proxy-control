# v4.0.2 — восстановление Naive и удобство управления

[English](#english) · **Русский**

## Русский

### Что изменилось

- Восстановление уже установленного NaiveProxy принимает сохранённый исторический план Caddy. Установщик проверяет владение бинарником, закреплённую версию и модуль forward-proxy, сохраняет обновления runtime, выполненные агентом, и не заменяет Caddy при repair. Новая установка по историческому плану запрещена.
- Страница подписки получила имя клиента, шаги подключения, компактные карточки приложений и доступов, светлую и тёмную темы, удобную мобильную вёрстку. Адреса подписок, форматы импорта, копирование и QR сохраняются.
- На обзоре обновлены карточки сервисов и строка ресурсов сервера, добавлена сводка MTProxy. Длинные имена узлов переносятся на телефоне; пояснение NaiveProxy честно учитывает служебные проверки.
- На карточках компонентов видны доступные обновления. «Обновить всё» сначала показывает список для подтверждения, обновляет последовательно, оставляет панель последней и останавливается при первой ошибке.
- Каталог маршрутизации содержит девять наборов сайтов и IP, включая MetaCubeX, MetaCubeX Lite, Re:filter, ru-direct и golukon Lite. Для источников доступны ручное скачивание и расписание автообновления.
- Палитра акцентных цветов расширена до 13 вариантов. Обновлены руководства по установке, маршрутизации и эксплуатации нативного Rust runtime.

### Обновление

Следуйте [руководству по обновлению](https://github.com/dubr1k/proxy-control/blob/v4.0.2/docs/UPGRADING.ru.md): проверьте опубликованную контрольную сумму `install-release.sh` и запустите `bash install-release.sh --update`. В парке сначала обновляйте связанные узлы, затем центральную панель. Перед обновлением сохраните резервную копию.

Установщик изменился в части восстановления Naive/Caddy; поведение скрипта скачивания не менялось, опубликованная копия закрепляет версию и SHA-256 архива 4.0.2. Контракты Fleet v2 и форматы подписок не менялись. Для перехода с 3.3.0 используйте проверенный скрипт `--update`, а не кнопку обновления старой панели; Fleet v1 требует отдельной миграции до обновления.

## English

### Changes

- Recovery of an already installed NaiveProxy accepts the saved historical Caddy plan. The installer checks binary ownership, the pinned build and the forward-proxy module, preserves agent-managed runtime updates and does not replace Caddy during repair. Historical plans remain forbidden for fresh installations.
- The subscription page gains the client name, connection steps, compact app and access cards, light/dark themes and mobile layouts. Subscription URLs, import formats, copy actions and QR codes are preserved.
- Refresh service cards and the server resource row on the overview; add an MTProxy summary. Wrap long node names on phones and explain that NaiveProxy traffic includes service healthchecks.
- Component cards highlight available updates. “Update all” confirms the list, updates sequentially with the panel last and stops at the first error.
- The routing catalogue offers nine site/IP datasets, including MetaCubeX, MetaCubeX Lite, Re:filter, ru-direct and golukon Lite. Sources support manual downloads and scheduled refreshes.
- Expand the accent palette to 13 colours and update installation, routing and native Rust runtime guides.

### Upgrade

Follow the [upgrade guide](https://github.com/dubr1k/proxy-control/blob/v4.0.2/docs/UPGRADING.md): verify the published checksum of `install-release.sh`, then run `bash install-release.sh --update`. Update linked nodes before the central panel and keep a restorable backup.

The installer changes Naive/Caddy recovery; download-script behaviour is unchanged, and the published copy pins the 4.0.2 archive version and SHA-256. Fleet v2 contracts and subscription formats are unchanged. Use the verified `--update` script, not the old panel's update button, to move from 3.3.0; Fleet v1 requires a separate migration before updating.
