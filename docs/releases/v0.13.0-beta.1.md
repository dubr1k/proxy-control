## Русский

### Исправлено

- В мобильных карточках клиентов и узлов квадратные плитки с обрезанными инициалами заменены круглыми пиктограммами человека и сервера. Имена, состояния и действия остались на своих местах.

- «Быстрые настройки» на узком экране больше не стоят в одной строке с первым переключателем: заголовок отдельно, каждый пункт занимает строку, флажки выровнены по центру строки. Настройки и их смысл не менялись.
- В обоих README актуализировано название текущего выпуска; заголовок опубликованной v0.12 перечисляет и правки её перевыпуска.

### Обновление с v0.12

Перед обновлением сохраните образ панели, согласованную online-копию её SQLite-базы, каталог `secrets/` и `.env*`. Проверьте SHA-256 скачанного архива по файлу `SHA256SUMS` выпуска. В каталоге установки перенесите `panel/`, `VERSION` и документацию из проверенного архива, **не заменяя** секреты, сертификаты, `.env*` или `version-overrides/`. Затем со своим прежним полным набором overlay-файлов:

```bash
docker compose --project-name mtproxy <ваши --env-file и -f> up -d --build --no-deps --wait panel
docker exec proxy-control-panel cat /app/VERSION  # 0.13.0-beta.1
```

При проблеме возвращайте прежний образ **и согласованную с ним базу**, затем проверьте здоровье панели и связанных узлов. Узлы обновляются до центра, по одному; не запускайте команды лабораторной переустановки на боевых хостах.

## English

### Fixed

- Square tiles with truncated initials on mobile client and node cards are replaced by round person and server pictograms. Names, states and actions retain their meaning.
- Multi-line grant cards on mobile no longer become oversized ovals; they have normal rounded corners.
- On narrow screens, the “Quick settings” heading no longer shares a row with the first toggle. Each option occupies a full row with a vertically aligned checkbox. Routing behavior is unchanged.
- Both READMEs now identify the current release, and the published v0.12 title includes its reissue fixes.

### Upgrading from v0.12

Save the current panel image, a consistent online SQLite backup, `secrets/` and `.env*` first. Verify the downloaded archive against the release `SHA256SUMS`. Copy `panel/`, `VERSION` and documentation from the verified archive, **not** the secrets, certificates, `.env*` or `version-overrides/`. Use the host's exact existing Compose overlay set:

```bash
docker compose --project-name mtproxy <your --env-file and -f options> up -d --build --no-deps --wait panel
docker exec proxy-control-panel cat /app/VERSION  # 0.13.0-beta.1
```

For rollback restore the previous image **and its matching database generation**, then check panel and linked-node health. Upgrade nodes before the central panel, one host at a time; never run disposable-lab reset commands on a production host.
