# Proxy Control 4.0.7

Панель включена в архив готовым статическим бинарником. Установка и обновление больше не компилируют её Rust-код на каждом сервере. Упаковка контейнера использует новый каталог проверенного выпуска; постоянный Cargo-кэш не нужен.

Неизменившиеся менеджеры не назначаются на пересборку из-за одной смены номера поколения общей библиотеки. Установщик и публикуемый install-release.sh получают тот же бинарник, что и обновление панели.

Для обновления скачайте install-release.sh и install-release.sh.sha256 из этого выпуска, выполните `sha256sum --check install-release.sh.sha256`, затем `bash install-release.sh --update`. Сохраняются резервирование и откат при ошибке. Клиентские доступы и настройки сохраняются.
