# v3.1.0 — обзор в прямом эфире, карточки протоколов одного вида

[English](#english) · **Русский**

Дата: 2026-10-20. Предыдущий выпуск: [v3.0.1](https://github.com/dubr1k/proxy-control/releases/tag/v3.0.1).

## Русский

### Что нового

- **«Ресурсы сервера» в прямом эфире.** Карточка на обзоре больше не ждёт очередного опроса: она получает тот же живой поток, что и экран «Мониторинг», и обновляется прямо на месте каждые 2 секунды. Проценты и объёмы меняются, полосы плавно сдвигаются, плашка «В норме / Нагружен» следует за нагрузкой. Под заголовком пульсирует точка «в прямом эфире» со временем последнего снимка: сразу видно, что данные живые.
- **Одни и те же числа везде.** CPU на карточке теперь среднее за секунду, как в мониторинге, а не мгновенный замер. Память, swap и диск берутся из того же снимка, поэтому обзор и «Мониторинг» больше не расходятся.
- **Карточки протоколов одного вида.** У MTProxy, Mieru, AmneziaWG, TrustTunnel и NaiveProxy теперь одинаковое устройство:
  - заголовок со статусом;
  - «Активные доступы» и «Отключённые»;
  - одна плитка «Трафик» на всю ширину: значение в одну строку (↑ принято · ↓ отдано), под ним что именно считается.

  Карточки в ряду выровнены, значения не переносятся на вторую строку ни на компьютере, ни на телефоне.
- **Ничего не потерялось.** Соединения и активные IP MTProxy, версии доступов AmneziaWG, адрес NaiveProxy и пометка «только закрытые CONNECT-туннели» теперь в подписи под трафиком.

### Что важно знать

- Настраивать ничего не нужно. Если мониторинг выключен (`PANEL_METRICS_ENABLED=0`), карточка ресурсов, как и раньше, обновляется раз в 5 секунд.
- Изменился только интерфейс панели: API, база, конфигурация и установщик не менялись. Обновление пересобирает только панель.
- **Обновляетесь с 2.x?** Сначала прочитайте заметки [v3.0.0](https://github.com/dubr1k/proxy-control/releases/tag/v3.0.0) и [v3.0.1](https://github.com/dubr1k/proxy-control/releases/tag/v3.0.1). Это обновление тоже переименует стек Docker из `mtproxy` в `proxy_panel_by_dubr1k`: службы встанут меньше чем на минуту. Мост MTProxy заменится на Go-версию, а нагрузка служб в простое заметно снизится.

### Новая установка

Используйте Ubuntu 24.04 LTS x86-64 и обычного пользователя с `sudo`, не вход под root. Подготовьте DNS-имена и следуйте [руководству по установке](https://github.com/dubr1k/proxy-control/blob/v3.1.0/README.md#установка-человеком) и [справочнику установщика](https://github.com/dubr1k/proxy-control/blob/v3.1.0/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v3.1.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v3.1.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки контрольной суммы.

### Обновление

Сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v3.1.0/docs/BACKUP_RESTORE.ru.md), скачайте и проверьте те же файлы, затем выполните:

```bash
bash install-release.sh --update
```

Порядок обновления флота прежний: сначала узлы, центральная панель последней. Тома Docker, базу и секреты при обновлении не удаляйте. Подробнее: [обновление](https://github.com/dubr1k/proxy-control/blob/v3.1.0/docs/UPGRADING.ru.md).

## English

### What's new

- **«Server resources» live.** The card on the overview no longer waits for the next poll: it takes the same live stream as the «Monitoring» screen and updates in place every 2 seconds. Percentages and volumes change, the bars slide, the «В норме / Нагружен» pill follows the load. A pulsing «live» dot under the title carries the time of the latest snapshot, so it is plain that the data is live.
- **The same numbers everywhere.** CPU on the card is now the one-second average the monitor uses instead of an instantaneous reading. Memory, swap and disk come from the same snapshot, so the overview and «Monitoring» no longer disagree.
- **One shape for every protocol card.** MTProxy, Mieru, AmneziaWG, TrustTunnel and NaiveProxy are now built the same way:
  - the head with the status;
  - «Active accesses» and «Disabled»;
  - one «Traffic» tile across the card: the value on one line (↑ received · ↓ sent), what it counts under it.

  The cards of a row line up and no value wraps onto a second line, on a computer or a phone.
- **Nothing was dropped.** MTProxy's connections and active IPs, AmneziaWG's access versions, the NaiveProxy host and its «closed CONNECT tunnels only» note are now in the caption under the traffic.

### Good to know

- Nothing to configure. With the monitor switched off (`PANEL_METRICS_ENABLED=0`) the resource card refreshes every 5 seconds as before.
- Only the panel's interface changed: the API, the database, the configuration and the installer did not. The update rebuilds the panel only.
- **Updating from 2.x?** Read the notes of [v3.0.0](https://github.com/dubr1k/proxy-control/releases/tag/v3.0.0) and [v3.0.1](https://github.com/dubr1k/proxy-control/releases/tag/v3.0.1) first. This update also renames the Docker stack from `mtproxy` to `proxy_panel_by_dubr1k`: the services stop for under a minute. The MTProxy bridge is replaced by its Go version, and the services' idle load drops noticeably.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v3.1.0/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v3.1.0/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v3.1.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v3.1.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v3.1.0/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The fleet update order is unchanged: nodes first, central panel last. Do not delete Docker volumes, the database or secrets as part of an update. More: [upgrading](https://github.com/dubr1k/proxy-control/blob/v3.1.0/docs/UPGRADING.md).
