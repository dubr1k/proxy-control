# v1.3.2 — AmneziaWG на сервере без ufw

[English](#english) · **Русский**

Дата: 2026-10-17. Предыдущий выпуск: [v1.3.1](https://github.com/dubr1k/proxy-control/releases/tag/v1.3.1).

## Русский

### Что изменилось

- **AmneziaWG на сервере без `ufw`.** Политика пересылки Docker — `DROP`, и без правил туннели не выпускают трафик в сеть. Служба `deploy/awg-forward.service` (systemd) после каждого запуска Docker идемпотентно добавляет разрешения для интерфейсов туннелей в цепочку `DOCKER-USER`. Случай описан в `AMNEZIAWG.ru.md`. На сервере с `ufw` ничего не меняется: установщик сам добавляет правила.
- Остальное без изменений: миграций базы нет, протокол Fleet и установщик не менялись.

### Установка на новый сервер

Требования: Ubuntu 24.04 LTS x86-64, собственные DNS-имена и обычный пользователь с `sudo`. Не запускайте мастер непосредственно от root. Подробно — [установка](https://github.com/dubr1k/proxy-control/blob/v1.3.2/README.md#установка-человеком) и [справочник](https://github.com/dubr1k/proxy-control/blob/v1.3.2/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге скачайте файлы **именно v1.3.2**:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.3.2/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.3.2/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки SHA-256. Мастер спросит домены и состав установки; на одном сервере с существующим Nginx/3x-ui выбирайте соответствующий режим сосуществования.

### Обновление существующей установки

Сначала сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v1.3.2/docs/BACKUP_RESTORE.ru.md). Скачайте и проверьте два файла командами выше, затем вместо запуска мастера выполните:

```bash
bash install-release.sh --update
```

В парке связанных панелей штатный порядок — узлы, затем центр. После обновления проверьте состояние служб и обновите подписку в клиентском приложении. Не удаляйте контейнерные тома, базу или секреты ради обновления.

### Ограничение проверки выпуска

Выпуск проверен автоматическими тестами затронутых областей, без нового полного установочного прогона. Служба пересылки нужна только серверу без ufw.

## English

### Changes

- **AmneziaWG on a server without `ufw`.** Docker's forwarding policy is `DROP`, and without rules the tunnels do not let traffic out. The systemd service `deploy/awg-forward.service` idempotently adds allowances for the tunnel interfaces to the `DOCKER-USER` chain after every start of Docker. The case is described in `AMNEZIAWG.en.md`. On a server with `ufw` nothing changes: the installer adds the rules itself.
- Everything else is unchanged: no database migrations, and the Fleet protocol and the installer did not change.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v1.3.2/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v1.3.2/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.3.2/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.3.2/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds. The wizard asks for domains and components. Select the appropriate coexistence mode when Nginx/3x-ui is already installed.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v1.3.2/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The normal fleet update order is nodes first, central panel last. Check service health afterwards and refresh the existing subscription. Do not delete Docker volumes, the database or secrets as part of an update.

### Validation limitation

This release is checked by automated tests of the touched areas, without a new full installer acceptance run. The forwarding service is only for a server without ufw.
