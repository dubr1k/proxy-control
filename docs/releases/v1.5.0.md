# v1.5.0 — случайные порты AmneziaWG

[English](#english) · **Русский**

Дата: 2026-10-18. Предыдущий выпуск: [v1.4.0](https://github.com/dubr1k/proxy-control/releases/tag/v1.4.0).

## Русский

### Что изменилось

- Порты AmneziaWG больше не стандартные 51820–51822: установщик выбирает свободный случайный UDP-порт на каждую версию (10240–32000), стабильный для сервера при плане, установке и обновлении. Порты можно задать вручную: вопрос мастера (Enter принимает выбранные), `ports` в TOML, `--ports` у `scripts/enable-amneziawg.sh`.
- На экране «AmneziaWG» появилась кнопка «+ AmneziaWG доступ»: имя, версии (можно несколько) и узел; после выдачи открывается окно с конфигами и QR.
- Уже работающие серверы порты не меняют сами: чтобы сменить, запустите `scripts/enable-amneziawg.sh --ports 1.5=…,2.0=…,3.1=…` (старые правила ufw снимаются) и выдайте клиентам новые конфиги.

### Установка на новый сервер

Требования: Ubuntu 24.04 LTS x86-64, собственные DNS-имена и обычный пользователь с `sudo`. Не запускайте мастер непосредственно от root. Подробно — [установка](https://github.com/dubr1k/proxy-control/blob/v1.5.0/README.md#установка-человеком) и [справочник](https://github.com/dubr1k/proxy-control/blob/v1.5.0/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге скачайте файлы **именно v1.5.0**:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.5.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.5.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки SHA-256. Мастер спросит домены и состав установки; на одном сервере с существующим Nginx/3x-ui выбирайте соответствующий режим сосуществования.

### Обновление существующей установки

Сначала сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v1.5.0/docs/BACKUP_RESTORE.ru.md). Скачайте и проверьте два файла командами выше, затем вместо запуска мастера выполните:

```bash
bash install-release.sh --update
```

В парке связанных панелей штатный порядок — узлы, затем центр. После обновления проверьте состояние служб и обновите подписку в клиентском приложении. Не удаляйте контейнерные тома, базу или секреты ради обновления.

### Ограничение проверки выпуска

Выпуск проверен автоматическими тестами затронутых областей, без нового полного установочного прогона. Экран появляется на сервере, где включён AmneziaWG.

## English

### Changes

- AmneziaWG no longer uses the well-known ports 51820–51822: the installer picks a free random UDP port per version (10240–32000), stable for the server across plan, install and update. Ports can be set by hand: a wizard question (Enter accepts the picked ones), `ports` in the TOML, `--ports` of `scripts/enable-amneziawg.sh`.
- The «AmneziaWG» screen has a «+ AmneziaWG access» button: a name, versions (several allowed) and a node; after issuing, the window with the configs and QR opens.
- Servers that already run do not change ports on their own: to change them, run `scripts/enable-amneziawg.sh --ports 1.5=…,2.0=…,3.1=…` (old ufw rules are removed) and give clients new configs.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v1.5.0/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v1.5.0/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.5.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v1.5.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds. The wizard asks for domains and components. Select the appropriate coexistence mode when Nginx/3x-ui is already installed.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v1.5.0/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The normal fleet update order is nodes first, central panel last. Check service health afterwards and refresh the existing subscription. Do not delete Docker volumes, the database or secrets as part of an update.

### Validation limitation

This release is checked by automated tests of the touched areas, without a new full installer acceptance run. The screen appears on a server where AmneziaWG is enabled.
