# v1.0.1 — любые версии компонентов, региональные geodata с автообновлением

[English](#english) · **Русский**

Дата: 2026-09-29. Предыдущий выпуск: [v1.0.0](https://github.com/dubr1k/proxy-control/releases/tag/v1.0.0).

> Правка панели, агента обновлений, менеджера Mieru и менеджера Xray-router: без миграции базы и изменения Fleet API. После обновления панели пересоберите менеджеры Mieru и Xray-router — см. «Обновление с v1.0.0». Полный список опубликованных файлов и контрольные суммы — на [странице выпуска](https://github.com/dubr1k/proxy-control/releases/tag/v1.0.1).

## Русский

### Добавлено

- **Любая версия на экране «Версии».** У каждого компонента — Telemt, NaiveProxy/Caddy, Mieru/mita, Xray-router — в выпадающем списке несколько последних выпусков в обе стороны: группа «Новее установленной» и группа «Откат на прежнюю». Кнопка называется «Установить», диалог говорит «Обновить» или «Откатить». Как и раньше, агент проверяет SHA-256 выпуска, сохраняет копию и откатывает неудачную установку. Панель предлагается только вперёд: её база мигрирует, старая сборка на ней не запустится, поэтому откат панели — полное восстановление из копии. То же на карточке узла → «Обновления».
- **Региональные источники geodata.** К Loyalsoldier и пину Xray добавлены «Россия — runetfreedom» (списки `ru-blocked`, `ru-available-only-inside`), «Иран — chocolate4u» (`category-ir`, `geoip:ir`) и «v2fly» (официальные списки без региональных дополнений). Каждое скачивание сверяется с опубликованной контрольной суммой.
- **Автообновление geodata по умолчанию.** Новый Xray-router сразу берёт Loyalsoldier и обновляет списки раз в сутки. Роутер, где geodata никто не настраивал, переходит на то же при обновлении; если вы сами выбрали источник или пин, выбор сохраняется.
- **Время обновления geodata.** Новые списки перезапускают роутер и на секунды рвут его соединения, поэтому ежедневное обновление ждёт выбранного часа — по умолчанию 02:00 UTC (05:00 по Москве). Час меняется в «Источник…»: любой из 24 или «в любой час». В строке geodata видно, когда списки проверялись последний раз и когда будет следующая проверка.
- **Региональные быстрые настройки маршрутизации.** «Заблокированное в РФ → через WARP» (нужен источник «Россия — runetfreedom», переключатель это подписывает), «Китайские домены и IP → напрямую», «Иранские домены и IP → напрямую». Во встроенной инструкции — два новых сценария: «Заблокированное в России — через WARP» и «Китайские сайты напрямую».

### Изменено

- **Mieru принимает любую mita.** Список «проверенных» версий убран: mita 3.38 и более новые ставятся с экрана «Версии». Менеджер записывает конфигурацию целиком той командой, которую знает бинарь (с 3.38 — `replace config`, раньше — `apply config`), и после каждой записи читает её обратно. Если результат не совпал, изменение откатывается и панель сообщает об ошибке, а не оставляет его молча.

### Исправлено

- **Откат изменения Mieru проверяется.** Если откат не вернул прежнюю конфигурацию, менеджер больше не называет его успешным, а сообщает, что нужно восстановление.
- **Файлы geodata больше 64 МБ.** Российские списки весят около 74 МБ; предел поднят до 128 МБ.
- **Ошибка перезапуска роутера после новых списков** теперь видна в строке geodata, а не теряется.
- **Пин geodata отставал от Xray.** С источником «архив Xray-core» после обновления Xray роутер переходит на списки из нового архива.
- **Скачивание geodata больше не задерживает перезапуск упавшего Xray.** Оно идёт в отдельном потоке.
- **Проверка обновлений NaiveProxy отвечала «422».** Модуль forwardproxy для NaiveProxy переехал на ветку `naive`, старой ветки больше нет; агент берёт коммит оттуда, и новые версии Caddy снова находятся.

### Обновление с v1.0.0

1. «Версии» → «Проверить обновления» → карточка «Proxy Control / панель» → `1.0.1` → «Установить». Узел обновляется из центра: «Узлы» → узел → «Обновления».
2. Карточка панели скажет «Изменились менеджеры: mieru_manager, xray_router_manager». Пересоберите их с набором overlay вашей установки (Xray-router — только если он установлен):

   ```bash
   cd /opt/mtproxy-shared443
   docker compose --env-file .env --env-file .env.mieru --env-file .env.xray-router --env-file .env.naive \
     -f compose.yaml -f compose.mieru.yaml -f compose.xray-router.yaml -f compose.naive.yaml \
     up -d --build --no-deps --wait mieru-manager xray-router
   ```

3. Теперь с «Версий» ставится mita 3.38. Роутер, где geodata не настраивали, сам скачает свежие списки Loyalsoldier (один короткий перезапуск роутера).

## English

### Added

- **Any version on the Versions screen.** Each component — Telemt, NaiveProxy/Caddy, Mieru/mita, Xray-router — lists several recent releases both ways in its dropdown: «Новее установленной» (newer than installed) and «Откат на прежнюю» (roll back). The button reads «Установить» (Install), the dialog says Update or Roll back. As before, the agent checks the release's SHA-256, keeps a copy and rolls a failed install back. The panel is only ever offered forward: its database migrates and an older build does not start on it, so going back is a full restore. The same on a node card → Updates.
- **Regional geodata sources.** Next to Loyalsoldier and the Xray pin: «Russia — runetfreedom» (`ru-blocked`, `ru-available-only-inside`), «Iran — chocolate4u» (`category-ir`, `geoip:ir`) and «v2fly» (the official lists without regional additions). Every download is checked against its published checksum.
- **Automatic geodata refreshes by default.** A new Xray-router starts on Loyalsoldier and refreshes the lists daily. A router whose geodata nobody set up moves to the same on upgrade; a source or pin you chose yourself is kept.
- **Geodata refresh time.** New lists restart the router and drop its connections for a few seconds, so a daily refresh waits for the chosen hour — 02:00 UTC by default. Change it under «Источник…» (Source): any of the 24 hours or «в любой час» (any hour). The geodata line shows when the lists were last checked and when the next check is due.
- **Regional routing quick settings.** «Заблокированное в РФ → через WARP» (blocked in Russia → via WARP; needs the «Russia — runetfreedom» source, and the toggle says so), «Китайские домены и IP → напрямую» (Chinese domains and IPs → direct), «Иранские домены и IP → напрямую» (Iranian → direct). The built-in guide has two new scenarios for them.

### Changed

- **Mieru takes any mita.** The list of «verified» versions is gone: mita 3.38 and newer install from the Versions screen. The manager writes the configuration as a whole with the verb the binary knows (`replace config` from 3.38, `apply config` before) and reads it back after every write. A mismatch rolls the change back and the panel reports it instead of leaving it silently.

### Fixed

- **A Mieru rollback is checked.** A rollback that did not restore the previous configuration is no longer reported as successful; the manager says recovery is needed.
- **Geodata files over 64 MB.** The Russian lists weigh about 74 MB; the limit is 128 MB now.
- **A router restart failure after new lists** now shows on the geodata line instead of being lost.
- **The geodata pin lagged behind Xray.** With the «Xray-core archive» source, the router moves to the new archive's lists after an Xray update.
- **A geodata download no longer delays restarting a dead Xray.** It runs in its own thread.
- **The NaiveProxy update check answered «422».** NaiveProxy's forwardproxy module moved to the `naive` branch and the old one is gone; the agent takes the commit from there and finds new Caddy releases again.

### Upgrading from v1.0.0

1. «Версии» → «Проверить обновления» → the «Proxy Control / панель» card → `1.0.1` → «Установить». A node is updated from the central: «Узлы» → the node → «Обновления».
2. The panel card says «Изменились менеджеры: mieru_manager, xray_router_manager». Rebuild them with your installation's overlays (the Xray-router only where it is installed):

   ```bash
   cd /opt/mtproxy-shared443
   docker compose --env-file .env --env-file .env.mieru --env-file .env.xray-router --env-file .env.naive \
     -f compose.yaml -f compose.mieru.yaml -f compose.xray-router.yaml -f compose.naive.yaml \
     up -d --build --no-deps --wait mieru-manager xray-router
   ```

3. mita 3.38 now installs from the Versions screen. A router whose geodata was never set up fetches fresh Loyalsoldier lists by itself (one short router restart).
