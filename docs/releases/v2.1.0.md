# v2.1.0 — TrustTunnel: приложения-клиенты и подписка для форков sing-box

[English](#english) · **Русский**

Дата: 2026-10-19. Предыдущий выпуск: [v2.0.1](https://github.com/dubr1k/proxy-control/releases/tag/v2.0.1).

## Русский

### Что нового

В этом выпуске доступ TrustTunnel подогнан под приложения, которые его действительно принимают.

- **«Как подключить».** В окне доступа TrustTunnel, в окне выдачи и на странице подписки появился список приложений: AdGuard TrustTunnel для iOS и Android (ссылка `tt://` или QR; [App Store](https://apps.apple.com/us/app/trusttunnel/id6755807890), [Google Play](https://play.google.com/store/apps/details?id=com.adguard.trusttunnel)), клиент командной строки TrustTunnel (файл TOML), Throne (профиль вручную), Surge (строка политики), Clash Verge Rev, FlClash, Mihomo Party, ClashMi (подписка Clash), Hiddify и NekoBox (подписка sing-box), а также Shadowrocket и сообщественные GUI (импорт не проверен: проверьте `tt://` или TOML, либо введите вручную). Что мы сами не запускали, помечено «не проверено нами».
- **«Данные для ручной настройки».** Карточка с сервером, портом, логином, паролем (скрыт, пока не нажмёте «Показать»), SNI, протоколом (HTTP/2, QUIC выключен), сертификатом в PEM и строкой политики Surge; у каждого поля своя кнопка копирования. Для Throne: Ctrl+N → Тип «TrustTunnel» → заполнить поля → OK, галочку QUIC не включать.
- **TrustTunnel в подписке sing-box для форков ядра.** В официальном sing-box исходящего TrustTunnel нет, и он отвергает конфиг с неизвестным исходящим целиком, поэтому лента несёт его только клиентам на форках: Throne, NekoBox, NyameBox, NekoRay и Hiddify опознаются по User-Agent (когда `format` не указан или `format=singbox`) либо параметром `client=throne|nekobox|nyamebox|hiddify`. Официальный sing-box, SFA, SFI, Karing и неизвестные клиенты получают прежнюю ленту. Свои клиенты на форках можно добавить переменной `PANEL_SINGBOX_FORK_CLIENTS` (через запятую, например `karing,streisand`).
- **Что проверено.** На стенде ядро hiddify-sing-box, собранное из исходников (в выпусках его пока нет), принимает исходящее, запрос через него даёт 200, а официальный sing-box 1.14.3 тот же JSON отвергает. Ядра NekoBox и Throne запустить не удалось: у них в матрице совместимости `unproven`. Если Throne проигнорирует исходящее из подписки, воспользуйтесь карточкой «Данные для ручной настройки». Подробно — [TRUSTTUNNEL.ru.md](https://github.com/dubr1k/proxy-control/blob/v2.1.0/TRUSTTUNNEL.ru.md), раздел «Клиенты».
- **Исправлено: нецентрованные подписи.** Текст в залитых кнопках (например, «Ссылка» на экранах MTProxy, Mieru и Naive) и пункты нижней панели на телефоне теперь стоят ровно по центру.

### Что важно знать

- Ломающих изменений нет, настраивать ничего не нужно. **Установщик в этом выпуске не менялся.**
- Обновляется панель. Подписки отвечают с `Vary: User-Agent`; ссылки и токены подписок прежние.

### Новая установка

Используйте Ubuntu 24.04 LTS x86-64 и обычного пользователя с `sudo`, не вход под root. Подготовьте DNS-имена и следуйте [руководству по установке](https://github.com/dubr1k/proxy-control/blob/v2.1.0/README.md#установка-человеком) и [справочнику установщика](https://github.com/dubr1k/proxy-control/blob/v2.1.0/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.1.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.1.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки контрольной суммы.

### Обновление

Сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v2.1.0/docs/BACKUP_RESTORE.ru.md), скачайте и проверьте те же файлы, затем выполните:

```bash
bash install-release.sh --update
```

Порядок обновления флота прежний: сначала узлы, центральная панель последней. Тома Docker, базу и секреты при обновлении не удаляйте. Подробнее: [обновление](https://github.com/dubr1k/proxy-control/blob/v2.1.0/docs/UPGRADING.ru.md).

## English

### What's new

This release fits a TrustTunnel access to the apps that actually take it.

- **«How to connect».** The TrustTunnel access window, the issue window and the subscription page now list the apps: AdGuard TrustTunnel for iOS and Android (the `tt://` link or the QR; [App Store](https://apps.apple.com/us/app/trusttunnel/id6755807890), [Google Play](https://play.google.com/store/apps/details?id=com.adguard.trusttunnel)), the TrustTunnel command-line client (the TOML file), Throne (a profile by hand), Surge (a policy line), Clash Verge Rev, FlClash, Mihomo Party, ClashMi (the Clash subscription), Hiddify and NekoBox (the sing-box subscription), and Shadowrocket and the community GUIs (import unverified: check `tt://` or TOML, or enter by hand). What we did not run ourselves is marked «не проверено нами» (not verified by us).
- **«Details for manual setup».** A card with the server, port, username, password (hidden until you press «Show»), SNI, protocol (HTTP/2, QUIC off), the certificate in PEM and the Surge policy line; every field has its own copy button. For Throne: Ctrl+N → Type «TrustTunnel» → fill in the fields → OK, and leave QUIC unticked.
- **TrustTunnel in the sing-box subscription for fork cores.** Official sing-box has no TrustTunnel outbound and rejects a config with an unknown outbound as a whole, so the feed carries it only for clients on forks: Throne, NekoBox, NyameBox, NekoRay and Hiddify are recognised by User-Agent (when `format` is absent or `format=singbox`) or by `client=throne|nekobox|nyamebox|hiddify`. Official sing-box, SFA, SFI, Karing and unknown clients get the feed as before. Add your own fork-core clients with `PANEL_SINGBOX_FORK_CLIENTS` (comma-separated, for example `karing,streisand`).
- **What was verified.** On the lab host a hiddify-sing-box core built from source (no release has it yet) accepts the outbound, a request through it returns 200, and official sing-box 1.14.3 rejects the same JSON. The NekoBox and Throne cores could not be run, so they are `unproven` in the compatibility matrix. If Throne ignores the outbound from the subscription, use the «Details for manual setup» card. More: [TRUSTTUNNEL.en.md](https://github.com/dubr1k/proxy-control/blob/v2.1.0/TRUSTTUNNEL.en.md), «Clients».
- **Fixed: off-centre labels.** The text in filled buttons (for example “Link” on the MTProxy, Mieru and Naive screens) and the items of the phone's bottom bar now sit exactly in the centre.

### Good to know

- There are no breaking changes and nothing to configure. **The installer did not change in this release.**
- The panel changes. Subscriptions answer with `Vary: User-Agent`; subscription links and tokens are unchanged.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v2.1.0/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v2.1.0/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.1.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.1.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v2.1.0/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The fleet update order is unchanged: nodes first, central panel last. Do not delete Docker volumes, the database or secrets as part of an update. More: [upgrading](https://github.com/dubr1k/proxy-control/blob/v2.1.0/docs/UPGRADING.md).
