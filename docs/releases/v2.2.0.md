# v2.2.0 — мониторинг по клиентам для Mieru и NaiveProxy

[English](#english) · **Русский**

Дата: 2026-10-19. Предыдущий выпуск: [v2.1.0](https://github.com/dubr1k/proxy-control/releases/tag/v2.1.0).

## Русский

### Что нового

В мониторе у Mieru и NaiveProxy появились строки по клиентам.

- **Mieru — вживую.** Менеджер Mieru читает накопительные байты по пользователям из `mita get metrics` (новый маршрут `/v1/traffic`, у линий маршрутизации складываются счётчики работающих слотов). Панель опрашивает его раз в 5 секунд, и в таблице «Активные клиенты» Mieru стоит рядом с остальными протоколами со скоростями ↓ и ↑. Общая скорость по-прежнему идёт от ядра; если счётчики ядра недоступны, она считается по этим же счётчикам.
- **NaiveProxy — по завершённым соединениям.** Строки по клиентам теперь есть всегда, а не только без счётчиков ядра. Caddy пишет объём соединения в журнал, когда соединение закрывается, поэтому скорость — среднее за минуту по завершённым соединениям; такие строки помечены «по завершённым». Опрос — раз в 15 секунд.
- **Скорость «Сейчас» на страницах протоколов.** Рядом с каждым пользователем на страницах MTProxy, Mieru, NaiveProxy, AmneziaWG и TrustTunnel стоит строка «Сейчас ↓ … · ↑ …» (у NaiveProxy — «За минуту …», у MTProxy общая скорость); обновляется раз в 5 секунд, пока вкладка открыта. Новый маршрут `GET /api/metrics/clients?protocol=…`.
- **Mieru: объёмы вместо «Недоступно».** Страница Mieru показывает ↑/↓ с запуска mita, обзор — суммы по Mieru. Квота остаётся приблизительной, история по периодам недоступна по-прежнему.
- В центральной панели строки приходят с узлов вместе с остальными данными: отдельная настройка не нужна.

### Что важно знать

- Ломающих изменений нет, настраивать ничего не нужно. **Установщик в этом выпуске не менялся.**
- Обновляются панель и менеджер Mieru. Пока менеджер Mieru на узле старше 2.2.0, строк Mieru по этому узлу нет — остальное работает как раньше.
- Mieru: счётчики mita обнуляются при перезапуске демона; панель считает это сбросом и не показывает отрицательных скоростей.

### Новая установка

Используйте Ubuntu 24.04 LTS x86-64 и обычного пользователя с `sudo`, не вход под root. Подготовьте DNS-имена и следуйте [руководству по установке](https://github.com/dubr1k/proxy-control/blob/v2.2.0/README.md#установка-человеком) и [справочнику установщика](https://github.com/dubr1k/proxy-control/blob/v2.2.0/docs/INSTALLER_REFERENCE.ru.md).

В пустом рабочем каталоге:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Продолжайте только после успешной проверки контрольной суммы.

### Обновление

Сделайте [резервную копию](https://github.com/dubr1k/proxy-control/blob/v2.2.0/docs/BACKUP_RESTORE.ru.md), скачайте и проверьте те же файлы, затем выполните:

```bash
bash install-release.sh --update
```

Порядок обновления флота прежний: сначала узлы, центральная панель последней. Тома Docker, базу и секреты при обновлении не удаляйте. Подробнее: [обновление](https://github.com/dubr1k/proxy-control/blob/v2.2.0/docs/UPGRADING.ru.md).

## English

### What's new

The monitor now has per-client rows for Mieru and NaiveProxy.

- **Mieru, live.** The Mieru manager reads cumulative per-user bytes from `mita get metrics` (a new `/v1/traffic` route; with routing lanes the counters of the running slots are added up). The panel polls it every 5 seconds, so Mieru sits in the «Active clients» table beside the other protocols with ↓ and ↑ rates. The total rate still comes from the kernel; when the kernel counters are unavailable it is computed from these same counters.
- **NaiveProxy, from finished connections.** Per-client rows now exist always, not only without kernel counters. Caddy writes a connection's volume to its log when the connection closes, so the rate is a one-minute average over finished connections; those rows are marked «from finished». Polled every 15 seconds.
- **A «Now» line on the protocol pages.** Beside every user on the MTProxy, Mieru, NaiveProxy, AmneziaWG and TrustTunnel pages there is a «Now ↓ … · ↑ …» line (NaiveProxy: «Per minute …», MTProxy: the total rate); it refreshes every 5 seconds while the tab is open. New route `GET /api/metrics/clients?protocol=…`.
- **Mieru: volumes instead of «Unavailable».** The Mieru page shows ↑/↓ since mita started and the overview shows the Mieru totals. The quota stays approximate and the per-period history stays unavailable.
- On the central panel the rows arrive from the nodes with the rest of the data: no setting is needed.

### Good to know

- There are no breaking changes and nothing to configure. **The installer did not change in this release.**
- The panel and the Mieru manager change. While a node's Mieru manager is older than 2.2.0 that node has no Mieru rows — everything else works as before.
- Mieru: mita's counters restart with the daemon; the panel treats that as a reset and never shows a negative rate.

### Fresh installation

Use Ubuntu 24.04 LTS x86-64 and a regular user with `sudo`, not a root login. Prepare your DNS names and follow the [installation guide](https://github.com/dubr1k/proxy-control/blob/v2.2.0/README.en.md#installation-by-a-human) and [installer reference](https://github.com/dubr1k/proxy-control/blob/v2.2.0/docs/INSTALLER_REFERENCE.en.md).

In an empty working directory:

```bash
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.0/install-release.sh
curl -fsSLO https://github.com/dubr1k/proxy-control/releases/download/v2.2.0/install-release.sh.sha256
sha256sum --check install-release.sh.sha256
bash install-release.sh
```

Continue only after checksum verification succeeds.

### Upgrading

Make a [backup](https://github.com/dubr1k/proxy-control/blob/v2.2.0/docs/BACKUP_RESTORE.en.md), download and verify the same files, then run:

```bash
bash install-release.sh --update
```

The fleet update order is unchanged: nodes first, central panel last. Do not delete Docker volumes, the database or secrets as part of an update. More: [upgrading](https://github.com/dubr1k/proxy-control/blob/v2.2.0/docs/UPGRADING.md).
