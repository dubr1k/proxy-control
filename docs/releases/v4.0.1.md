# v4.0.1 — компактный интерфейс и подписки

[English](#english) · **Русский**

## Русский

### Что изменилось

- Карточки узлов и клиентов показывают главное: состояние, количество доступов и проблемы. Подробности открываются отдельно; данные узла распределены по вкладкам, технические сведения и редкие действия свёрнуты.
- В окне клиента подписка отделена от управления доступами. Для подписки можно выбрать систему и приложение, добавить её в приложение или скопировать ссылку; QR, полный адрес и инструкция раскрываются по запросу.
- Собственное название доступа в подписке включает протокол. Адреса подписок, форматы профилей и схемы импорта приложений сохраняются.
- Исправлены центрирование значков на телефонах, копирование при недоступном Clipboard API, возврат из окон кнопкой «Назад» и проверка версий связанного узла. Неизвестное состояние доступа видно сразу.
- Второстепенные действия протоколов и маршрутизации перенесены в меню. С локального узла убраны вводящие в заблуждение сообщения старого агента и пояснение про локальные протоколы.
- Упорядочены руководства и ссылки документации, подробные разделы README свёрнуты.

### Обновление

Следуйте [руководству по обновлению](https://github.com/dubr1k/proxy-control/blob/v4.0.1/docs/UPGRADING.ru.md): проверьте опубликованную контрольную сумму `install-release.sh` и запустите `bash install-release.sh --update`. В парке сначала обновляйте связанные узлы, затем центральную панель. Установщик и протоколы установки не менялись; опубликованный скрипт закрепляет архив 4.0.1.

## English

### Changes

- Node and client cards show status, access counts and problems. Details open separately; node information is split into tabs, with technical fields and occasional actions collapsed.
- The client window separates subscriptions from access management. Choose a platform and app, add the subscription to the app or copy its link; expand QR, the full URL and instructions when needed.
- Custom subscription access names include the protocol. Subscription URLs, profile formats and app import schemes are preserved.
- Fix mobile icon centring, copying without the Clipboard API, browser Back navigation and linked-node version checks. Unknown access state is visible immediately.
- Move secondary protocol and routing actions into menus. Remove misleading legacy-agent messages and the local-protocol explanation from the local node.
- Reorganise guides and documentation links, and collapse detailed README sections.

### Upgrade

Follow the [upgrade guide](https://github.com/dubr1k/proxy-control/blob/v4.0.1/docs/UPGRADING.en.md): verify the published checksum of `install-release.sh`, then run `bash install-release.sh --update`. Update linked nodes before the central panel. The installer and installation protocols are unchanged; the published script pins the 4.0.1 archive.
