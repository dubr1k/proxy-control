# v0.6 Verification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** доказать, что каждая функция v0.2–v0.5 работает на настоящем хосте через настоящие API и настоящий браузер; починить найденное; выпустить v0.6.0-beta.1 по поручению владельца после подтверждения.

**Architecture:** матрица «функция → доказательство» (`docs/VERIFICATION_MATRIX.md` ↔ `tests/fixtures/verification-matrix.json`, тест-страж) → аудит маршрутов (`scripts/dev/route-coverage.py` в `full`) → tier `ui` (`scripts/lab/ui-acceptance.py`, headless Chrome по CDP на `ams-test`, каждый view, две роли, 390 px) → дыры бэкенда (`lab-host` без `KEEP_INSTALL`, `lab-container`, `managed-xui`, `backup-restore`, фикстура миграций v0.2) → живая проверка AMS_Z (обновление + UI только чтение) → заметка, публикация.

**Tech Stack:** Python 3.12, FastAPI, vanilla JS, headless Chrome/CDP (websocket на stdlib, как в `routing-shots.py`), pytest; гейт только на `ams-test` через `scripts/dev/remote-gate.sh`; длинные прогоны — detached на хосте (`setsid nohup`) с опросом лога.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.6-verification-design.md`.

## Global Constraints

- Никаких новых функций; исправления — с тестом-регрессией и строкой матрицы `fixed-in-0.6`.
- Каждый tier — идемпотентен и убирает за собой (узел стенда после прогона = до прогона).
- Секреты не попадают ни в отчёты, ни в скриншоты (`_SECRET_SHAPES`).
- Коммиты без трейлеров; всё тестируется на `ams-test`, живая проверка — только AMS_Z.

## Структура файлов

- `docs/VERIFICATION_MATRIX.md`, `tests/fixtures/verification-matrix.json`, `tests/test_verification_matrix.py`
- `scripts/dev/route-coverage.py` (+ вызов в `remote-gate.sh full`)
- `scripts/lab/ui-acceptance.py` (CDP-драйвер + сценарии по view; впитывает `routing-shots.py`/`router-shots.py`), `scripts/dev/remote-gate.sh` tier `ui`
- `scripts/lab/guest-runner.sh` сценарий `backup-restore`
- `tests/fixtures/panel-v0.2.sqlite3` (или генератор) для цепочки миграций
- `docs/releases/v0.6.0-beta.1.md`, `docs/releases/assets/v0.6.0-beta.1/*.png`, `CHANGELOG*.md`, `VERSION`, `CONTINUE-HERE-v0.6.md`
