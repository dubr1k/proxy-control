# v0.4 Routing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** оператор задаёт из UI egress-политику каждого прокси-сервиса узла (напрямую / через WARP / блокировки, first-match), видит честный предпросмотр компиляции под backend узла и применяет её транзакционно с откатом — локально и на подключённых панелях.

**Architecture:** нейтральный IR (ADR 006) в панели → компилятор на backend (`naive_native` = Caddy forwardproxy `upstream`+`acl`, `mieru_native` = mita `egress`) → типизированный egress API менеджеров (`get/plan/apply/rollback`, revision, readback, журнал; ADR 007 — менеджер владеет egress-блоком) → локально напрямую, удалённо — секция `egress` поколения Fleet v2 под capability `egress.v1`. Установщик выносит WARP в `[egress]` и сеет начальный egress один раз.

**Tech Stack:** Python 3.12, FastAPI, pydantic 2, SQLite/WAL, httpx, `http.server` менеджеров на UDS, Caddy 2.11.4 + klzgrad/forwardproxy `d62c80d`, mita 3.36, vanilla JS, pytest; гейт только на `ams-test` через `scripts/dev/remote-gate.sh`.

**Spec:** `docs/superpowers/specs/2026-09-14-v0.4-routing-design.md` (+ `docs/superpowers/specs/2026-09-10-proxy-control-vnext-design.md` Phase 6, ADR 006, ADR 007).

## Global Constraints

- Ветка `feature/vnext-v0.4-routing`; коммиты без трейлеров `Co-Authored-By`/`Claude-Session` (правило владельца).
- Каждый тест/гейт — только на `ams-test` (`scripts/dev/remote-gate.sh quick|full|compose|lab-host|fleet|routing`); macOS не авторитетен. `AMS_Z` — только живая проверка в Task 13 после зелёного гейта; пользователи `AMS_Z` не трогаются, хост возвращается в исходное состояние.
- Миграции только additive, продолжают `MIGRATIONS` с версии 13 (`LEARNED_V13`) → `ROUTING_V14`; frozen identifiers `docs/COMPATIBILITY.md` не меняются; Fleet v1 не трогается.
- Секреты: политики, compiled-документы, `identity`, `observed`, audit — secret-free. URL WARP только в env менеджеров.
- Лимиты: политика ≤ 128 правил, ≤ 64 доменов/CIDR и ≤ 32 портов на правило, compiled ≤ 16 KiB на протокол; тело push узла остаётся 64 KiB.
- MTProxy/Telemt — вне маршрутизации везде (422 `protocol_out_of_scope`, нет egress API).
- Fail-closed: недостижимый провайдер → отказ применения; `fallback=approved_direct` — явный выбор.
- Документация двуязычная там, где пара `*.en.md`/`*.ru.md` уже есть.
