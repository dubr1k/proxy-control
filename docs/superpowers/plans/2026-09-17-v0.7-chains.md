# v0.7 Chains Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** выходы `direct | warp | block | node:<guid>` и цепи узлов в политике маршрутизации; политика на полосу (сервис или доступ клиента) для NaiveProxy и Mieru; экран «Маршрутизация и цепи»; доставка через Fleet v2; установщик с relay-портом и слотами Mieru; гейт и живая проверка AMS_Z → ams-test; `v0.7.0-beta.1`.

**Architecture:** спека [`2026-09-17-v0.7-chains-design.md`](../specs/2026-09-17-v0.7-chains-design.md); спайк [`docs/spikes/CHAINS_PER_CLIENT.md`](../../spikes/CHAINS_PER_CLIENT.md). Слой за слоем снизу вверх: роутер (intent v2, полосы, relay, цепи) → менеджеры сервисов (обработчики Caddy, слоты mita) → модель/компилятор/сервис панели → Fleet → установщик → UI → лаборатория → документация → релиз.

**Tech Stack:** как v0.5/v0.6; всё тестируется на `ams-test` (`remote-gate.sh`), длинные прогоны detached.

## Global Constraints

- TDD: тест-регрессия до реализации; матрица сверки — строка на каждый новый маршрут/экран.
- Ключи полос и UUID relay не появляются ни в одном API-ответе, аудите, отчёте, логе, тесте-фикстуре с реальным значением.
- Совместимость: intent схемы 1 и поколения v0.6 принимаются; узел v0.6 получает поколение без полос/цепей.
- Коммиты без трейлеров; секреты — вне репозитория.
